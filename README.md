# 萌宠养成 · QQ 宠物网页版（v3.0 完整版）

竖屏移动端网页版宠物养成游戏。**纯原生 HTML + CSS + JavaScript，无任何第三方依赖、无框架、无后端**，所有数据存于 `localStorage`，开箱即用。

## 技术规格
- 基准宽度 375px，全程使用 `vw/vh` 响应式单位，竖屏占满 `100vh`，禁止横向滚动
- 宠物与图标全部使用 **emoji** 实现，无需任何外部图片资源
- 数据自动存入 `localStorage`，刷新/关闭页面不丢失，支持离线时间结算
- 风格：Q 版卡通、暖色调、大圆角按钮，适配手机触控

## 文件结构
| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面骨架：领养页、主界面、底部导航、统一弹窗与 Toast 容器 |
| `style.css` | 全部样式（响应式、动画、装饰锚点定位） |
| `game.js` | 核心逻辑：状态机、主循环、商店/签到/广告/医院/成就/死亡轮回/离线结算 |
| `petConfig.js` | 8 种宠物配置：专属衰减系数、解锁顺序、装饰锚点 |
| `itemConfig.js` | 消耗品、永久道具、装饰物品配置 |
| `event.js` | 通用 + 8 种宠物专属随机事件池 |
| `growth.js` | 三阶段（幼年/成年/老年）成长与年龄计算 |
| `achievement.js` | 6 项成就条件与检测 |

## 核心玩法
1. **领养**：首次进入选择宠物并起名，确认后进入主界面（初始 50 金币）
2. **四维属性**：健康度 / 饱腹度 / 快乐度 / 清洁度（0–100）
   - 基础衰减 + 宠物专属系数；饱腹=0、清洁<30、快乐<20 触发健康/快乐惩罚
   - 健康 ≤20 进入生病状态；健康 =0 弹病危提示，持续 24 小时未救治则死亡
3. **操作**：🍖喂食、🛁清洁、🎾玩耍、💤休息（休息时健康回复、快乐下降）
4. **商店**：消耗品即时生效、永久道具长期生效、装饰可购买并穿戴在宠物身上（帽子/眼镜/围巾/背景，按宠物种类精准定位）
5. **每日签到**：7 天一轮，断签后可在 ⚙️设置 或签到弹窗内**消耗金币补打卡**续上连续天数
6. **看广告**：每次 3 秒，观看结束立即到账金币（每日上限 5 次）
7. **随机事件**：每日首次登录触发，正面/负面/中性，8 种宠物各有专属事件
8. **成就系统**：初次领养、七日存活、百日寿星、千金散尽、购物达人、全宠物收藏家
9. **成长阶段**：按累计在线时长算年龄（24 小时 = 1 天），幼年→成年→老年，外观与收益随阶段变化
10. **死亡与轮回**：健康归零持续 24 小时 → 死亡弹窗（复活 200 金币 / 重新领养继承遗产），每死亡 1 次解锁 1 种新宠物
11. **离线结算**：最多结算 24 小时；超过 24 小时进入休眠（无衰减无收益），超过 7 天健康强制降到 10 并弹病危警告

## 运行方式
直接用浏览器打开 `index.html` 即可；或本地起任意静态服务器：

```bash
# 任选其一
python -m http.server 8000
# 然后访问 http://localhost:8000/index.html
```

> 移动端体验最佳：建议用手机浏览器或将桌面浏览器窗口调至竖屏窄宽度（375px 基准）。

## 操作入口
- 底部导航：`🛒 商店` / `📅 签到` / `📺 广告` / `📊 属性` / `⚙️ 设置` / `🏆 成就`
- 主界面顶部：4 条竖向数值进度条 + 右上角金币
- 中间宠物区：点击宠物有反馈动画
